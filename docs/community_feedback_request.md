# Community feedback request

Suggested message for the Vesuvius Challenge Discord or another official
community channel:

> I have released InkSurf v0.1.0, a fail-closed evidence/provenance auditor for
> surface-based ink workflows: https://github.com/BioMarco/Inksurf
>
> It checks whether apparently agreeing predictions are genuinely independent,
> verifies registration and labeled common support before comparison, audits
> disagreement/abstention semantics, and emits hash-bound claim ceilings. The
> repository includes a one-minute synthetic demo, bounded real-data workflows,
> 149 tests and preserved negative results on PHerc0814, PHerc0139 and
> PHerc1667.
>
> I would especially value feedback on: (1) whether the receipt/adapter contract
> fits VC3D or current ink-detection workflows; (2) one real workflow where the
> fail-closed gate would save reviewer time; and (3) any reproduction problem on
> Linux or Windows. Issues are enabled on the repository.

Do not describe InkSurf as detecting verified ink or letters. If someone tests
the tool, preserve their public issue/comment URL as evidence of community use
for the Progress Prize review.
